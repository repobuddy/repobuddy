## Which package do I install?

| I want to | Install |
| --- | --- |
| Write `test`/`coverage` scripts, check Jest dependencies | [`repobuddy`](/repobuddy/cli/) (CLI) |
| Give a coding agent repo chores (issues, dependency PRs, repo setup) | [`repobuddy`](/repobuddy/skills/) (agent plugin) |
| Test with Jest | [`@repobuddy/jest`](/repobuddy/jest/) |
| Test with Vitest in Node.js or jsdom | [`@repobuddy/vitest`](/repobuddy/vitest/) |
| [Run browser tests (Vitest + Playwright)](/repobuddy/vitest/guides/browser-tests/) | [`@repobuddy/vitest`](/repobuddy/vitest/) |
| [Assert the order code runs in](/repobuddy/vitest/guides/expect-order/) | [`@repobuddy/vitest`](/repobuddy/vitest/), or [`@repobuddy/test`](/repobuddy/test/) [with Jest](/repobuddy/test/guides/expect-order-with-jest/) |
| Lint and format with Biome | [`@repobuddy/biome`](/repobuddy/biome/) |
| Configure TypeScript (`tsconfig`) | [`@repobuddy/typescript`](/repobuddy/typescript/) |
| [Build a package as CommonJS and ESM](/repobuddy/typescript/guides/dual-cjs-esm-build/) | [`@repobuddy/typescript`](/repobuddy/typescript/) + [`repobuddy`](/repobuddy/repobuddy/) |

Each package's overview has its install command, the peer dependencies to install with it, and what it supports. The
`repobuddy` agent plugin installs through your coding agent, not as a dependency; see
[Install the skills](/repobuddy/skills/install/).
