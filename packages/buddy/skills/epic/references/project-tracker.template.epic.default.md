## Outcome

What is true when this is done, in one sentence.

## Key terms

- K1. **term**: what it means here, or the repo, file, app, job, or command it names.

## Scope

- S1. ...

## Non-goals

- N1. ... (adjacent work a reader would assume is in, left out on purpose)

## Open questions

- Q1. ... Spike: #123, or design issue: owner/repo#45.

## Child Issues

- [ ] #123 title

## Run order

| Wave | Child | Executor | Blocked by |
|---|---|---|---|
| 1 | #123 title | agent | none |

## Risks and irreversible steps

- R1. ... (the step, why it cannot be undone, and the confirmation it waits for)

## Done when

All child issues are done, and the outcome can be observed:

- [ ] D1. ... (a command to run, or a run to link)

## Research and sources

- Research: a link to the research artifact, or `Skipped: <reason>`.
- F1. ... (a fact the plan relies on, such as an id, count, or URL, and where it was read)
