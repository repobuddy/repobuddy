# Decision log

Append-only record of decisions taken on this project: what was decided, what else was considered,
and why one option won. Descriptive — no decision here is gated or tested. A superseded decision
stays in place and is marked superseded rather than edited away, because the reasoning that led to
it is what makes the replacement legible.

One file per decision, named `NNNN-short-title.md`, numbered in the order taken.
