# spec2

Design specs for the skills and capabilities of the `repobuddy` package, written with the `sdd2:spec` skill. Each folder holds one capability: `README.md` is its spec, and `graph.md` its decision graph when the behavior branches.

| Spec | Outcome |
| --- | --- |
| [epic](./epic/README.md) | Work too big for one issue is held on its tracker as an epic that can be carried out from its filed issues alone. |
